# Сбор отзывов только о майнорах в первой версии

## Статус

Принято.

## Контекст

Сервис предназначен для помощи студентам в выборе майнора.
В рамках Riskiest Assumption Test (RAT) проверяется гипотеза о готовности студентов оставлять отзывы.
Пять знакомых студентов отложили заполнение формы, поскольку не смогли сразу ответить на вопрос о преподавателях.

## Решение

В первой версии приложения собирать отзывы только о майнорах.
Отдельные отзывы о дисциплинах внутри майнора и преподавателях не реализовывать.
Вариант с отдельными отзывами о преподавателях отклонён из-за наблюдавшихся затруднений при заполнении формы.

## Последствия

- Снижается порог входа: форма отправки отзыва содержит меньше вопросов.
- Первая версия приложения не предоставляет отдельных отзывов о преподавателях и дисциплинах внутри майнора.
- При добавлении отзывов о преподавателях требуется расширение модели данных и доработка API.
